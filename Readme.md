# 🎬 Video Crop & Trim Tool

A modern browser-based video crop and trim application that allows users to trim videos and crop selected areas directly from the browser without uploading files to any server.

## ✨ Features

- 📂 Upload or drag & drop videos
- ✂️ Trim video duration
- 🖼️ Crop selected video area
- 🎞️ Export cropped + trimmed video
- ⚡ Local browser processing
- 🔒 Files never leave your computer
- 🎨 Modern glassmorphism UI
- 📱 Responsive design
- 🎥 Live video preview
- 🔊 Mute / unmute controls
- 📏 Multiple crop presets:
  - Full
  - Square
  - 9:16 Portrait
  - 16:9 Landscape

---

## 🚀 Technologies Used

- HTML5
- Tailwind CSS
- Vanilla JavaScript
- Canvas API
- MediaRecorder API
