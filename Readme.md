# 🎬 Video to GIF Converter

A modern browser-based **Video to GIF Converter** built with pure HTML, TailwindCSS, and JavaScript.

Convert videos into high-quality GIFs directly inside your browser — no upload required.

---

# ✨ Features

- 🎥 Video to GIF conversion
- ✂️ Free crop selection
- 🟩 Full / Square / 16:9 crop presets
- 🖱️ Drag & Drop video upload
- ▶️ Custom video controls UI
- 🔊 Mute / Unmute support
- ⏱️ Start & End time selection
- ⚡ "Use Current" quick buttons
- 🎞️ "Full Length" export button
- 📏 Multiple output resolutions
- 🎚️ GIF quality selector
- 📦 Local browser processing
- 🔒 No server upload
- 💻 Works fully offline after load

# ⚠️ Large Video Support

Large videos (including 4GB+ files) are supported because files are loaded locally using browser object URLs.

However:

- Long GIF exports may freeze the browser
- Recommended GIF duration:
  - 2–8 seconds
- Recommended output:
  - 480p or 720p for smoother export

# 📦 Installation

Just open the HTML file in your browser.

No build tools required.

```bash
double click index.html
```

or

```bash
open index.html
```

---

# 🛠️ How It Works

1. Upload or drag a video
2. Select crop area
3. Choose start/end time
4. Select output quality
5. Click "Generate GIF"
6. Download your GIF

---

# 🔒 Privacy

Everything happens locally in your browser.

Your files are never uploaded to any server.
